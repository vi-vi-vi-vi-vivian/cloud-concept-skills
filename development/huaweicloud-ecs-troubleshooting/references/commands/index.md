## 验证标记

- `实`：实际 API 返回成功。
- `实·空`：调用成功但无结果；未验证明细依赖链。
- `助`：实际执行 help 成功；未验证业务调用。
- `阻·调用`：业务调用受阻；操作帮助已核实。
- `阻·帮助`：帮助受阻；条目仅保留来源清单语义。

核验日期：2026-10-19。KooCLI：7.2.12。共 1282 个命令版本，33 个服务。
当前状态：助 1220；实 39；实·空 20；阻·调用 3。

验证结果只覆盖本次账号、区域、资源和时间。读取、执行、修改分别按“行为”列判断。

## 使用规则

- 详细参数查运行时 help；同版本帮助可在会话中复用。
- 依赖只在输入缺失时补齐。空列表、拒绝访问和成功明细是不同结果。
- 后续查询复用已有任务。需要新证据时再选择创建任务。
- 变更、主机执行、扫描和发送消息按当前明确授权执行。
- 返回对象决定后续标识。参数同名不保证资源标识可以互换。
- 列表按接口分页。数据未收全时记录范围，保留下一页标识。
