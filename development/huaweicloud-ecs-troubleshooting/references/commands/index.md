## 表格约定

| 字段 | 含义 |
| --- | --- |
| 命令 | 唯一标识：`服务/操作/版本`。执行时保留完整版本。 |
| 作用 | 动作、对象及必要影响。 |
| 输入与来源 | 关键资源标识；仅在缺失时查来源。普通参数查 help。 |
| 约束 | 会改变执行决策或容易出错的条件。 |

- `缺 X → Y`：仅在 X 未知时读取或调用 Y；来源链接不表示固定执行顺序。
- `字段: 类型`：类型是逻辑名称，不是 CLI 参数。同名参数不表示同一种资源标识。
- `—`：无额外契约说明；不表示没有必填参数。
- 字段绑定只在 [Helper](../helpers.md) 定义。已有标识直接复用。
- 需要判断核验范围时，按命令 ID 查[验证记录](../verification.md)。

执行前核对[Shared](../shared.md)的作用域、帮助与影响规则。已知命令时直接搜索命中行；链接锚点只负责定位，不要求读取整册。
