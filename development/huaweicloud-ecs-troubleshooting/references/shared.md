# Shared

- 使用已配置的 hcloud。缺少 CLI 或认证时说明缺口。
- 用 `--cli-profile` 和 `--cli-region` 选择已有配置和区域。API 要求 `project_id` 时使用对应区域的 IAM project。企业项目与 IAM project 分别处理。
- 用 `rtk proxy hcloud configure test` 检查本地配置格式。认证是否有效，以实际 API 响应为准。
- 命令行数组使用 `.1`、`.2`。详细参数、枚举和分页方式查当前操作的 help。
- 构造调用前核对所选操作的 help。同一会话、相同 CLI 版本和命令版本可复用；升级、元数据更新或参数错误后重新核对。
- 检查响应中的错误对象。CLI 退出码为 0 也可能表示调用失败。
- 保留资源范围和时间窗。指标毫秒时间戳与告警 ISO 8601 字符串分别按接口要求填写。
- 列表翻页直到所需范围完整。未收全时注明范围和下一页标识。
- 业务影响按契约判断。GET 可能启动检测；POST 可能只读取数据。
- 配置、调试输出、控制台日志和登录地址可能包含敏感内容。报告只保留诊断所需字段。

## 执行核对

| 时点 | 必须一致的内容 | 不一致时 |
| --- | --- | --- |
| 选择命令 | 完整命令 ID 与目标作用 | 重新选择并核验；不静默替换版本或相近操作 |
| 构造参数 | 已确认的 profile、region、IAM project、目标资源与时间窗 | 补齐缺失事实；作用域变化时重新确认资源 |
| 补齐标识 | Helper 的资源类型、选择条件与输出字段 | 多结果先定位目标；不把列表首项当默认目标 |
| 调用前 | 当前 help、契约影响及当前授权范围 | 差异影响参数或行为时暂停该操作；继续可独立获取的证据 |
| 接收响应 | 错误对象、目标身份、字段绑定及任务状态 | 分开记录失败、空结果与成功；异步请求已接受不等于任务完成 |

参数会触发同步、扫描、安装、修改或发送消息时，按该参数的实际影响核对授权。后续查询复用已有任务；创建任务不是读取结果的默认前置步骤。

## 工具入口

下表命令接在 `rtk proxy hcloud` 后。需要核验历史时查[验证记录](verification.md#cli-元工具)。

| 命令 | 作用 | 输入与来源 | 约束 |
| --- | --- | --- | --- |
| `version` | 读取 CLI 版本 | — | — |
| `configure test` | 检查本地配置格式 | 已有配置 | 不证明认证有效 |
| `configure list` | 读取配置项列表 | — | — |
| `configure show` | 读取指定配置项 | 已有 profile | — |
| `configure set` | 修改本地配置 | 目标 profile | 按授权范围配置认证与作用域 |
| `log show` | 读取 CLI 日志配置 | — | — |
| `log set` | 修改本地日志配置 | — | 按 help 选择级别 |
| `meta download` | 下载并修改元数据缓存 | — | 更新后重新核对所用操作的 help |
| `meta clear` | 删除本地元数据缓存 | — | 后续需重新获取帮助 |
| `update` | 修改本机 CLI 安装版本 | — | 更新后重新核对所用操作的 help |

## 诊断选项

以下选项附加到所选命令，详细格式查 help。

| 选项 | 用途与约束 |
| --- | --- |
| `--debug` | 输出调用信息；原命令仍执行。 |
| `--dryrun` | 预览请求；跳过目标业务 API，仍可能读取元数据或项目资料。 |
| `--skeleton` | 生成 JSON 入参骨架。 |
| `--cli-profile`、`--cli-region`、`--cli-project-id` | 选择配置、区域与默认项目。API 的 `project_id` 另按操作 help 填写。 |
| `--cli-domain-id`、`--cli-x-project-id` | 指定账号或鉴权项目；按 API 要求使用。 |
| `--cli-endpoint` | 排查端点选择；使用官方服务端点。 |
| `--cli-connect-timeout`、`--cli-read-timeout`、`--cli-retry-count` | 设置连接、读取超时与重试；重试不会修复权限拒绝。 |
| `--cli-query`、`--cli-output` | 筛选返回字段与显示格式；不改变服务端查询范围。 |
| `--cli-waiter` | 轮询原 API；使用前确认原操作只读。 |

命令发现与共享查询见 [Service](services.md)。
