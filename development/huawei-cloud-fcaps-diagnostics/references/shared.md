# 共同约束

- 绑定目标与时间窗：云查询绑定账号、区域和资源；主机查询绑定远程目标 OS；集群查询绑定 context、namespace 和对象身份。管理机 OS 不代表目标 OS。
- 首次使用查所选操作帮助；同一工具版本、操作与环境可复用。升级、参数错误或输出变化后重新核验。
- 表中变量是已解析输入，不是默认值。以参数数组传值；确需 shell 时分别转义每个参数，不拼接未验证文本或使用 eval。精确目标拒绝通配符及选项注入。
- “作用”表示直接观测，不表示故障结论。“约束”保留适用条件、执行影响和解释边界；`—` 不表示无必填参数。
- 同时检查退出状态、错误对象、目标身份及输出字段。无记录、无权限、工具缺失分别报告；截断或未翻完页时说明覆盖范围。
- 查询、探测、采样、扫描、修改按实际行为区分。已有任务直接查询；安装 Agent、创建诊断任务或执行修复不是默认前置步骤。
- 核对当前授权。额外影响未被覆盖时先给出具体动作；可独立执行的已授权查询继续进行。凭据只用于认证；报告仅保留必要证据。
